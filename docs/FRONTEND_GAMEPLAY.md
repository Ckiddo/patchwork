# T39：Bevy 对局场景与浏览器交互

更新：2026-09-13。

## 场景边界

战斗对局使用现有 Bevy 0.17 场景。入口仍是 `src/game.rs` 的 `run_game` 和 `NewGamePlug`；复用 `new_game/chessboard.rs` 的 Sprite 格子与内嵌方块、`new_game/patches.rs` 的外围布局和拼布子 Sprite。Yew 管理好友房、资源 HUD、操作栏、底部时间横条和结果面板。双图版、外围拼布、中立指示物、绿色候选框、落点预览均由 Bevy 绘制和拾取。

`AuthorityPlugin` 替代旧 `HelloUI` / 共享 `BoardGame` 的本地自由落子系统。旧模块保留供参考，正式场景不注册这些修改本地占格的系统。

| Bevy 组件 | 用途 |
|---|---|
| QuiltBoard / QuiltCell | 带 owner 的图版、格子；坐标从左上角开始 |
| PlacedPatchView | 已提交拼布的 owner 与 PieceId |
| PatchIncomeLabel | 已放置有收入拼布的单个 +N 标记，随权威快照显示和恢复 |
| PatchView | 冻结拼布 ID 和原始外围槽位 |
| CandidateFrame | 中立指示物之后三个候选的绿色边框 |
| NeutralMarker | 开局位于 1×2 前，购买后位于所选拼布原槽 |
| PlacementPreview | 独立的临时落点，合法绿色、非法红色 |

两个页面各自按认证身份映射“左对手、右自己”，对手格子不能驱动落点。外围固定 33 槽，顺时针排列；购买后隐藏原槽拼布，不把其余拼布重新排列。候选框周期 1.6 秒；浏览器启用 `prefers-reduced-motion` 时保持常亮。

双方图版上每块有收入的已放普通拼布显示一个深底浅黄的 `+N` 标记。标记选择该拼布接近中心的实际占格，按快照中旋转/翻面后的占格定位，不会落在凹形拼布的空洞中。每块只显示一次；零收入普通拼布、特殊 1×1 和尚未提交的预览不显示。标记实体复用、忽略鼠标拾取，刷新或断线恢复后依据正式快照重建显示。

HUD 的“每次收入 +N”是自己图版上所有拼布收入的总和。每经过一个纽扣收入点，这个总和加入可花费的纽扣余额；总和本身不会因领款再次增长。购买的新拼布在这次时间推进前计入总和，若购买时经过收入点，也会贡献收入。轨道收入点的说明显示双方当前总额。结算沿用 `game_core` 和权威服务端，前端标记不修改余额或累计收入。

## 输入与权威状态

1. 选择外围绿色框内的拼布，或点击 HUD 的候选编号。三个候选都可选中预览；纽扣不足时显示所需、当前和差额，无可用落点时显示原因。此时仍可旋转/翻面，但确认购买保持禁用。
2. 在右侧图版移动鼠标预览，左键点击合法格子直接放置；也可用方向键调整预览，再按 Enter 或点击“确认放置”。触屏走同一 Bevy Pointer 主按钮点击路径。旋转/翻面后保留归一化包围盒左上角锚点。
3. 图版左键、Enter 和确认按钮共用动作校验与提交路径；图版点击使用本次点击的格子，不依赖前一帧悬停位置。普通拼布发送现有协议的 `BuyAndPlace`，特殊拼布发送 `PlaceSpecialPatch`。越界、重叠、纽扣不足只显示无效预览，不提交；非本人回合、未选普通拼布或等待同步/回执时不能提交。请求等待期间沿用单个 pending 请求门禁；费用、收入、图版和时间均等待服务器的正式快照。
4. 在游戏区域右键、按 Esc 或点击取消可清除选择、落点和方向草稿，不扣费、不发送请求。右键不会打开游戏区域的浏览器菜单，松开右键也不会重新选布。取消草稿不撤回已发送的请求；等待回执期间购买仍锁定，刷新或断线恢复保留同一个请求 ID 和 payload。特殊拼布右键只取消落点预览，已领取的待放队列仍保留。

| 操作 | 按键 |
|---|---|
| 左转 | Q / Shift+R |
| 右转 | R |
| 翻面 | F |
| 取消草稿 | Esc / 游戏区域右键 |
| 确认落点 | 自己图版左键 / Enter / 确认按钮 |
| 微调落点 | 方向键 |

输入框、选择框和可编辑文本保留自己的按键行为。按钮聚焦时 Enter 使用按钮的原生点击，避免同时确认与触发其他按钮。

Yew 和 Bevy 使用单线程桥接：只有服务器状态或草稿变化时更新场景；鼠标移动和按钮点击不会重建画布。图版填充、候选框、选中框和预览实体复用。切换新对局才替换场景根节点。

## 同步、时间与结束

页面默认创建 `patchwork_custom_v1`。重新连接后先取得所属房间，再恢复快照/事件并完成 SyncAck，随后重发未确认的原动作。SyncRequired 保留原请求并显示等待提示，避免双方未同步时反复自动提交；版本冲突后重新同步。

前进按钮显示实际步数和总纽扣收益（步数奖励 + 途经收入）。领取特殊拼布后进入 1×1 专用放置模式，禁止普通购买/前进，必须处理完队列。底部时间横条一次显示 0–53，双方分通道显示；点击标记可查看收入说明或特殊拼布领取状态。

终局面板直接使用服务端结果：剩余纽扣、7×7 奖励和总分，空格不扣分。可以关闭面板查看图版，也可以返回大厅；双方离开已结束房间后重新建房、加入、准备、开始新局。
